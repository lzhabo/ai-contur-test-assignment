# Контур — передача проекта

> Историческая инструкция первой версии. Для текущего кода используйте [хендофф к сдаче](../../submission/handoff.md): пути `src/web`, режим `fake` и старые настройки ниже больше не актуальны.

Локальное приложение для одной чистой TypeScript-функции: автор → проверки → ревьюер → ваше подтверждение → применяющий агент. Две облачные модели через существующий Codex login, три роли. Код находится прямо в `/Users/lidia/Desktop/BIOSINGULARITY/agent-workspace`.

## Запуск

Проверенная среда: macOS, Node **26.9.0**, npm **11.19.1**, Codex CLI **0.156.1**. Требуется доступ аккаунта к `gpt-6-sol` и `gpt-6-luna`. Сначала `codex login status`; при отсутствии входа выполните `codex login` самостоятельно. Ключ в проект не записывается. Адаптер отклоняет другие версии CLI до проверки совместимости.

```sh
cd /Users/lidia/Desktop/BIOSINGULARITY/agent-workspace
npm ci
npm start
```

Откройте **http://127.0.0.1:4317**. Выберите пример или опишите функцию, запустите агентов, просмотрите функцию/тесты/ревью. «Подтвердить» вызывает третьего агента и сохраняет точную версию; «Отклонить» завершает задачу без результата. ZIP и путь появятся после сохранения. Закрытие вкладки не останавливает backend; Ctrl+C завершает сервер, та же команда восстанавливает историю. Неизвестный исход внешнего вызова требует отдельного явного повтора, расходующего бюджет.

## Где что находится

- `src/web` — интерфейс; `src/server` — LangGraph, HTTP, Codex, проверки и файлы; `src/shared` — контракты и лимиты.
- `.local-data/checkpoints.sqlite` — состояние; `.local-data/tasks/<id>/revisions` — версии; `result` — итог; `events.jsonl` — события. Для переноса истории копируйте всю `.local-data` после остановки сервера.
- `project-history/two-model-loop/` — исходник, ТЗ, архитектура, исследования, план, решения и фактический [отчёт проверок](../verification.md).
- `delivery/conversations/` — три настоящих фрагмента переписки с хешами; [demo.md](demo.md) — демонстрация; [limitations.md](limitations.md) — границы.

## Проверки и управляемые сбои

`npm run typecheck`, `npm test`, `npm run build`. Для чистого тестового контура:

```sh
APP_CODEX_MODE=fake APP_FAKE_SCENARIO=review_loop APP_DATA_DIR=.local-data/demo-loop APP_PORT=4318 npm start
```

Сценарии: `happy`, `review_once`, `review_loop`, `no_response`, `slow`. Fake отмечен в интерфейсе; для другого сценария берите новую папку. Реальные вызовы расходуют лимит аккаунта. Тестовый режим не продолжает сохранённую реальную задачу.

## Границы и открытые вопросы

Одна активная задача; синхронная функция, JSON-вход/выход, без сторонних импортов, сети и файлов. До 3 версий, 7 вызовов, 180 секунд на вызов; checks — до 5 секунд и 64 MiB. QuickJS не предоставляет Proxy и не принимает аксессоры/циклические значения как JSON. Проверки и ревью не доказывают полную корректность произвольной функции. После потери соединения нельзя гарантировать отсутствие повторной обработки в облаке. Дедлайн исходника — 03.10.2026, конец дня; часовой пояс сдачи не уточнён. Приёмку человеком и живую демонстрацию с вопросами нельзя заменить автоматическими тестами; их статус указан в отчёте.
