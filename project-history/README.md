# История работы над проектом

Здесь хранятся задания, исследования, планы, согласованные решения, результаты проверок и материалы для сдачи проекта. Для каждой работы координатор создаёт папку `project-history/<task-id>/`; документы добавляются по мере выполнения.

## Разделы

- [Первоначальная разработка](two-model-loop/brief.md) — требования, выбор решений и реализация приложения.
- [Переход на Express](express-migration/brief.md) — перенос сервера и проверки совместимости.
- [Переработка архитектуры](architecture-rework/brief.md) — структура кода, правила читаемости и проверки.
- [Материалы для сдачи](submission/README.md) — инструкция передачи, журнал решений, переписки и демонстрация.
- [Восстановление ролей агентов](agents-recovery/README.md) — результаты поиска, восстановления файлов и контрольные суммы.

Обычные документы: `brief.md` — постановка, `research.md` — исследование, `decisions.md` — договорённости, `plan.md` — план, `status.md` — состояние, `verification.md` — проверки. В `evidence/` сохраняются подтверждения, в `conversations/` — выбранные переписки.

Документы прежних этапов описывают соответствующие версии проекта. Текущие инструкции запуска находятся в [корневом README](../README.md).

29.09.2026 папка переименована из `tasks` в `project-history` по просьбе пользователя. Пути в сохранённых переписках, логах и исходных копиях файлов отражают момент их записи.
