## Как подготовлены файлы

- JSONL — исходные строки `response_item` с сообщениями пользователя и ассистента, скопированные побайтно в исходном порядке. Всего 20 сообщений: 6 + 4 + 10.
- Это выбранные фрагменты, а не полный экспорт всех чатов. Служебные записи, инструменты и внутренние рассуждения между сообщениями не включены. Выбор границ отражён в [manifest.json](manifest.json).
- Markdown — автоматически извлечённые тексты тех же сообщений. Добавлены только заголовки роли/времени, разделители и вводное описание; содержимое сообщений не переписано.
- Ответ из формы выбора во втором эпизоде сохранён в исходной служебной текстовой оболочке `<send_user_message_question_reply>`.
- Первые два фрагмента совпадают с ранее сохранёнными историческими evidence. Третий добавлен из сессии архитектурной переработки.
- Старые абсолютные ссылки внутри сообщений сохранены по требованию «как есть». Читать комплект можно без перехода по ним; текущие файлы перечислены в хендоффе.

Проверить SHA-256 из manifest можно командой `shasum -a 256 project-history/submission/conversations/*.jsonl` из корня репозитория. Сопоставление выбранных строк с локальными оригиналами выполнено при подготовке; лог — [conversation-integrity.txt](../evidence/conversation-integrity.txt).
