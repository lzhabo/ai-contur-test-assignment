# Контур — хендофф

Актуально на 28.09.2026, код `main` на `f537ce4`. Локальное приложение: автор пишет одну TypeScript-функцию, другая модель делает ревью, человек подтверждает версию, применяющий агент запрашивает сохранение. Сервер публикует проверенные байты. Поддерживаются чистые синхронные функции с JSON-входами/выходами, без сети, файлов и сторонних зависимостей.

## Как запустить

Из корня клонированного репозитория. Нужны Node.js 26+, npm; для настоящих моделей — сеть, доступ к моделям `gpt-6-sol` и `gpt-6-luna`, свободный лимит Codex и **Codex CLI 0.156.1 по пути `/opt/homebrew/bin/codex`**. Это закреплённый в коде путь проверенной macOS-среды; одного `codex` в PATH недостаточно.

```sh
node --version
npm ci
/opt/homebrew/bin/codex --version
/opt/homebrew/bin/codex login status
# Если входа нет, выполнить вход через ChatGPT и повторить проверку:
/opt/homebrew/bin/codex login
APP_CODEX_MODE=real APP_DATA_DIR=.local-data/submission-real npm start
```

Открыть [http://127.0.0.1:4317](http://127.0.0.1:4317). `npm start` сам собирает интерфейс. Автор и применяющий используют `gpt-6-sol`, ревьюер — `gpt-6-luna`; вызовы расходуют лимит аккаунта. Проверка входа должна показать `Logged in using ChatGPT`.

**Авторизация:** приложение использует вход внешнего Codex CLI того же системного пользователя. Кнопки входа, OAuth-потока и предварительной проверки сессии в приложении пока нет. Если требуется авторизация внутри интерфейса, это отдельная незакрытая доработка. Другой путь установки CLI требует изменения `CodexCliPort` в `src/server/codex/cli-port.ts`; переменной окружения для пути пока нет. Версия CLI проверяется строго.

Для запуска без Codex и облачных вызовов:

```sh
APP_CODEX_MODE=mock APP_MOCK_SCENARIO=review_once APP_DATA_DIR=.local-data/submission-mock npm start
```

В UI выбрать «Объединить интервалы» → «Запустить агентов» → посмотреть ревью и файлы → «Подтвердить» → «Скачать комплект ZIP». В mock и ошибочная первая версия, и ревью, и исправление заранее заданы адаптером; это проверка приложения.

## Где что лежит

| Путь | Содержимое |
| --- | --- |
| `src/client/{api,hooks,components,workflow}` | Запросы, данные/подписки, UI, рисунок процесса |
| `src/shared/` | Общие схемы и примеры |
| `src/server/tasks/` | Команды, граф LangGraph, вызовы ролей, восстановление |
| `src/server/{codex,code-runner,storage,routes}` | CLI/mock, QuickJS, хранение, HTTP/SSE |
| `tests/` | Unit/integration, браузерные и отдельные модельные проверки |

В `APP_DATA_DIR`: `checkpoints.sqlite` — состояние; `tasks/<id>/events.jsonl` — история; `revisions/` внутри задачи — версии; `result/` — подтверждённые файлы. `server-events.jsonl` — диагностика. Одна папка данных принадлежит одному серверу. Для второго сервера задайте другой каталог и `APP_PORT=4319`. `Ctrl+C` завершает сервер; повторите ту же команду для восстановления. При неизвестном исходе вызова нужен явный повтор в UI. Старые базы не импортируются.

## Проверки и открытые вопросы

`npm run check` — lint, типы, локальные тесты, сборка. `npm run test:e2e` — mock-путь в установленном Google Chrome. `QA_REAL_CODEX=1 npm run test:e2e` — настоящий Codex. `npm run test:live-review` — смешанный прогон: первая версия замокана с намеренной ошибкой, следующие три ответа настоящие. Исторические результаты и пределы проверок: [verification.md](../architecture-rework/verification.md). Сценарий показа: [demo.md](demo.md).

- Встроенный вход Codex и настройка пути CLI остаются открытыми; запуск на других ОС не подтверждён.
- Продукт допускает одну активную задачу; лимиты: 3 версии, 7 вызовов, до 180 секунд на вызов. Модельное одобрение и тесты не доказывают корректность для всех входов.
- После аварийного завершения backend может остаться процесс Codex; автоматическая уборка такого процесса не закрыта. Доказательство восстановления охватывает конкретный сбой автора, а не все точки выполнения.
- До переработки автор сомневалась в независимости ревью моделей, смысле тестов и возможности «отвечать за каждую строчку». Смешанная проба проверяет один сценарий; подтверждения, что личные сомнения полностью сняты, в чатах нет. [Журнал и источники](decisions.md).
