## Git и проверка первоисточников

Локальная история содержит 20 коммитов до `f537ce4`, включая документы, проверку совместимости, интеграцию, исправления, Express и переработку. Запись с названием `first commit` (`f2c3ffb`) не является первым коммитом репозитория — до неё сохранены более ранние этапы.

```sh
git log --graph --all --oneline --decorate
git log --reverse --format='%h %ad %s' --date=short
```

Сырые фрагменты сверены с локальными журналами соответствующих сессий Codex побайтно. [Manifest](conversations/manifest.json) содержит имена исходных сессий, номера строк, SHA-256 и число сообщений. Hash подтверждает неизменность файла после экспорта; сопоставление с исходным журналом выполнялось отдельно. Полные личные журналы Codex в репозиторий не копировались.
