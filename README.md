# Рабочая папка с агентами

Открой эту папку как проект в Codex и начни в ней новую задачу. Так проектные настройки и AGENTS.md смогут загрузиться для новой сессии. Если приложение предлагает доверить проектную конфигурацию, проверь её и подтверди доверие в интерфейсе.

## Начало работы

Отправь:

> Работаем по AGENTS.md. Ты координатор. Моя задача: [что нужно сделать, для кого и с какими ограничениями]. Используй подагентов для независимых частей работы. Начни с исследования аналогов и готовых решений на GitHub. Покажи отчёт и дождись обсуждения со мной. Код будем реализовывать после согласования решения и плана.

## Что где находится

- `AGENTS.md` — правила основного агента и делегирования.
- `.codex/config.toml` — включение подагентов и лимит до трёх одновременно, помимо основного агента; фактический предел также зависит от среды.
- `.codex/agents/` — пять ролей: researcher, planner, implementer, qa, reviewer. Можно запускать несколько implementer с разными заданиями. Пять описаний не означают пять постоянно работающих агентов.
- `workflow/PROCESS.md` — этапы, согласования и проверка результата.
- `tasks/` — документы и состояние отдельных задач.

Координатором является основной агент диалога: отдельный coordinator.toml ему не требуется. Именованные роли загружаются в поддерживающих этот формат клиентах. Создание файлов не запускает агентов и не является проверкой их загрузки.

Точка в начале имени делает папку скрытой в Finder. На macOS скрытые файлы показываются сочетанием Command+Shift+точка.

`.agents/skills/` — другое назначение: дополнительные навыки с файлом SKILL.md. Для этого стартового процесса навыки создавать не требуется.

## Код и параллельная работа

Стек и структуру кода выбираем после исследования конкретной задачи. Git-репозиторий пока не инициализирован. Перед использованием worktrees нужно инициализировать репозиторий и сделать базовый коммит. Worktrees могут физически находиться вне этой папки, но относятся к одному Git-проекту.

Модели, ключи API, подключения GitHub и права доступа здесь не заданы: роли используют доступные инструменты и настройки сессии. Доступ к закрытым репозиториям требует соответствующего подключения. Обычный поиск публичных проектов возможен через доступный web-поиск.
