# Перенос HTTP backend на Express

Цель: заменить Fastify на понятный для владельца проекта Express, сохранив внешние HTTP-контракты, TypeScript-типы, работу сервиса и интерфейса.

Пользователь подтвердил реализацию и проверки в отдельной задаче. Изменения остаются только в этом worktree; исходная рабочая папка и её незакоммиченные файлы не затрагиваются. База: `78ee49ded1ff5726962ee4ce3e992470d8f6593d`.

В объёме: JSON API, SSE, артефакты, ZIP, выдача SPA, запуск и остановка сервера, зависимости, тесты и документация. Бизнес-логика LangGraph, SQLite, Codex, QuickJS и DTO не меняется. Платные live модели не запускаются.
